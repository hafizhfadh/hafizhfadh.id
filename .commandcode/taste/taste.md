# Taste

- Prefers warm, editorial, human design over generic AI/SaaS aesthetics: warm ivory paper canvas, restrained accent colors (e.g., terracotta/sage against deep navy), expressive serif display typography, asymmetric compositions with generous whitespace, hairline rules instead of repeated card grids, and custom meaningful illustrations. Dislikes: dark dashboard/telemetry looks, repeated identical card grids, monospace for body copy ("terminal" looks), neon/purple SaaS accents, decorative fake dashboards or meaningless code snippets. Confidence: 0.85
- For UI work, verify quality by inspecting the actual rendered site (screenshots at real desktop and mobile viewports) — never judge design quality from source code alone. Confidence: 0.85
- Never fabricate professional facts: no invented client names, project names, results, testimonials, logos, or certifications — use only verifiable, documented information. Confidence: 0.9
- For content/consultancy sites, prefer multi-page information architecture: a concise homepage that converts and links to dedicated detail pages (progressive disclosure), with one canonical structured data source reused across pages — never duplicate the same content/paragraphs on multiple pages. Confidence: 0.75
