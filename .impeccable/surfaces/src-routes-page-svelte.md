# Surface brief — src/routes/+page.svelte (single-page consultancy site)

## Scope & mode

Single-route Persuade surface: premium personal engineering consultancy for Hafizh Fadhlurrohman. Visitor = technical decision-maker deciding whether to start a conversation. Replacement visual world (old dark obsidian dashboard is the anti-reference).

## Audience, job, action, proof, constraints

- Job: make a CTO/founder feel they have met a capable, approachable principal engineer and act.
- Action: start the conversation (mailto-structured discovery intake form) — the primary action must be unmistakable in the first viewport.
- Proof: verified production metrics (70% cost reduction, 33–40% spend reduction, 1.6 TB DB at ≤500ms, 200k+ installs), experience history, ISO 27001 work. All copy claims stay factual from data files.
- Constraints: brief-pinned Warm Technical Editorial direction (user override): warm ivory canvas, deep navy anchors, terracotta accents, sage technical accents, editorial serif display, no card grids, no dark dashboard aesthetics, no neon. Craft floor bans apply (no eyebrow kickers, no repetitive cards, mono only for code/data/measurement).

## Direction contract

THESIS: A personal letter from a senior engineer, set like a fine engineering annual report — warmth carrying authority. It refuses the category default of dark telemetry dashboards, and refuses the generic cream+serif+terracotta rendition by committing to a complete editorial system: navy anchor sections, sand hairlines, sage technical linework, true bylines and pull-quotes, rare and purposeful terracotta.

OWN-WORLD: Ivory #F4EFE5 ground, cream #FAF8F2 panels, sand #E5D8C4 hairlines, deep navy #172B40 anchor sections (impact ledger, contact invitation, footer), warm charcoal #282C2B text, muted secondary #5C5A52, terracotta #C85A3A display accents with fired-clay #B04A2C interactive states, sage #687C70 line art and markers. Instrument Serif display + Manrope body + IBM Plex Mono strictly for data, dates, and technical annotations. Hairline rules, generous whitespace, and typographic composition replace boxed cards; every section has its own composition inside one system.

STORY: The visitor meets a person, not a platform: reads how he works, sees verified numbers set like an annual-report ledger, understands that engagement begins with a conversation rather than a quote, and writes to him directly.
